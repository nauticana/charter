# Harbor Manufacturing Example

Status: Conceptual example for specification 1.0.0

Harbor Manufacturing is a fictional, vendor-neutral company used to exercise Charter end to end. It manufactures configured industrial pumps, purchases components, fulfills customer orders, and maintains installed equipment.

The example provides conceptual instances and walkthroughs for:

- An enterprise and organization hierarchy
- Positions, roles, responsibilities, and assignments
- Human and agent identities
- An order-exception value stream, process, tasks, and execution instance
- Authority, delegation, approval, and separation-of-duties cases
- A non-normative SAP S/4HANA Cloud binding example
- Capability, data, authority, and event bindings
- Action evidence, exceptions, and escalation
- Baseline, target, gap, and roadmap architecture states

All documents use the same fictional order-exception scenario and stable example identifiers. The current Markdown establishes the scenario before machine-readable schemas are released. It is not a conformance fixture or conformance claim.
