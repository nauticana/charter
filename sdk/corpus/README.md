# Corpus Package

`Corpus` indexes documents by namespace and id and resolves same-namespace or explicitly namespaced references. `Loader` is the interface, `BaseFSLoader` the file-system implementation; `Parser` builds documents from JSON; `Decode[T]` produces typed documents. `Source` is the abstract loading contract behind every provider (a `Corpus` is one, and `Union` reads several, such as definitions and the evidence they cite, as one), and `AbstractDocumentProvider` adds kind validation, reference resolution, and effective-time queries over it; `ResolveAs`, `ListAs`, and `EffectiveAs` return typed documents. Its `FetchVersion` reads a stored version of a document by the label its kind declares, an empty label reading the current version; a `Corpus` holds one version of each document. `DefinitionVersion` reads the version a versioned definition kind declares, `Published` whether a document is past drafting, `ContentDigest` the `sha256` digest of a document's JSON canonicalized as RFC 8785 specifies, the content digest a derivation records, and `Corpus.Derivations` lists the documents derived from a source.
