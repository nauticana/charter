# Authority SDK

`Evaluator` and `GrantSource` interfaces, `AbstractEvaluator` (enterprise, actor, capability, resource, validity, organizational context, and typed-limit comparison; embed it and supply a `GrantSource`), `BaseGrantSource` (in-memory) and `DocumentGrantSource` (any `corpus.Source`), delegation-depth and separation-of-duties helpers. `ApprovalGate` and `ApprovalSource` interfaces with `AbstractApprovalGate` (approved action, material-inputs digest, subjects, limits, and validity mode; embed it and supply an `ApprovalSource`), `BaseApprovalSource`, and `DocumentApprovalSource`. Evaluation is fail-closed and returns namespaced references, a result, and a reason.
