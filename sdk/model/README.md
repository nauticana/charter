# Model Package

Structs only: the `Envelope` base every typed document embeds, `Ref`/`ObjectRef`/`Validity`/`Limit` value types, the `AuthorityChain` request-context value, the `Kind` constants, one hand-maintained struct per catalogued kind grouped by schema domain, and the generic `Document`. An authority chain is ordered immediate delegator first and carries grant references and bounds, never credentials. `Ref` carries the one method in the package, its JSON codec, because `encoding/json` requires it on the type. The test round-trips every Harbor document through its struct and back through its schema, so catalogued document structs add no fields absent from the normative contract and drop none.
