# Model Package

Structs: the `Envelope` base every typed document embeds, `Ref`/`ObjectRef`/`Validity`/`Limit` value types, the `AuthorityChain` request-context value, the `Kind` constants, one hand-maintained struct per catalogued kind grouped by schema domain, and the generic `Document`. An authority chain is ordered immediate delegator first and carries grant references and bounds, never credentials. Methods are JSON codecs, which `encoding/json` requires on the type, and a few reads of a type's own data: `Ref`, `Precondition`, `EvidenceRequirement`, and `Source` decode a string or an object, and a `Document` encodes as the document itself, its raw bytes. The test round-trips every Harbor document through its struct and back through its schema, so catalogued document structs add no fields absent from the normative contract and drop none.
