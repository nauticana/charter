# Capability SDK

`Catalog` serves capability contracts (`BaseCatalog`); `VersionPolicy` decides contract compatibility. `AbstractInvoker` runs the governed pipeline around an abstract `binding.Executor`: version, actor lifecycle, authority, approval, separation of duties (`SodChecker`), information governance (`Invocation.InformationUses` against `information.Evaluator`, decisions evidenced), binding feature support, idempotency (`Ledger`), execution, declared-outcome and business-error verification, and an `ActionRecord` appended to the evidence sink for every decision. An `Escalator` (`BaseEscalator` over `BaseAccountableRecipient`) turns unknown and failed outcomes into an `ExceptionRecord` and an `Escalation` to the accountable authority of the agent's definition. Tool and system adapters implement the transport; they never replace the contract.
